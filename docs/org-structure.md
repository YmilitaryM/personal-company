# 公司组织架构

## 总览

**规模**: 30人 AI Agent 团队
**产品范围**: 机器学习算法、IoT场景应用、智能体知识库、App & Web
**运作模式**: 需求方（人类）输入需求 → AI 团队自运转 → 交付验收

## 管理层

### CTO (1人)
- 技术战略决策
- 架构审批
- 技术债务管理
- 跨项目资源协调
- 向需求方汇报

### 产品经理 (3人)
- PM-A: ML算法 + Agent知识库 方向
- PM-B: IoT场景应用 方向
- PM-C: App & Web 方向
- 职责: 需求分析、PRD编写、Backlog管理、验收标准定义

### 市场经理 (1人)
- 市场调研分析
- 竞品分析
- GTM策略
- 用户反馈收集

## 执行层

### 项目组长 / Tech Lead (3人)
- TL-A: 负责ML+Agent方向，管理4名高级工程师 + 2名专业工程师
- TL-B: 负责IoT方向，管理4名高级工程师 + 2名专业工程师
- TL-C: 负责App&Web方向，管理4名高级工程师 + 2名专业工程师
- 职责: 任务分解、技术方案、代码审查、进度跟踪、向CTO汇报

### 高级工程师 (12人)
- 每组4人，负责核心功能开发
- 技术方案设计
- Code Review
- 指导初级工程师

### 专业工程师 (6人)
- ML专业工程师 ×2: 算法开发、模型训练、数据处理
- IoT专业工程师 ×2: 嵌入式开发、通信协议、硬件对接
- Agent专业工程师 ×2: 知识库构建、RAG系统、智能体开发

### 设计师 (4人)
- UI设计师 ×2: 视觉设计、设计系统维护、组件设计
- UX设计师 ×2: 交互设计、用户研究、可用性测试

## 监管层

### 独立评审团 (3人)
- 跨领域全栈专家
- 独立于任何项目组
- 对项目各阶段进行评审
- 过半赞成票(≥2/3)才能通过

### 监管职能
- **过程监管**: 流程合规性检查、工作流执行监控
- **质量监管**: 代码质量、设计规范、测试覆盖率
- **时间监管**: 里程碑跟踪、进度偏差预警、交付日期管理

## 决策层级

```
需求方（人类）
  │
CTO ── 技术决策
  │
项目组长 ── 项目决策
  │
专业组长 ── 技术执行决策
  │
工程师 ── 实现决策

评审团 ── 独立于决策链，横向评审
```

## 汇报关系

```
工程师 → 专业组长 → 项目组长(Tech Lead) → CTO → 需求方
                                          ↑
                    评审团（独立评审，向CTO报告评审结果）
```
