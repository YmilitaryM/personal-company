## 部署流程

### 标准部署 (每周二/四 14:00-16:00)

1. **部署前检查** (30min前)
   - [ ] 所有测试通过 (CI green)
   - [ ] DG3 评审通过
   - [ ] 数据库迁移脚本已review
   - [ ] 回滚方案已确认

2. **Staging 部署**
   ```
   git checkout release/vX.Y.Z
   ./deploy/staging.sh
   ```

3. **Staging 验证** (30min)
   - [ ] Smoke test 通过
   - [ ] 关键业务流程正常
   - [ ] 性能指标无异常
   - [ ] PM 签字确认

4. **生产部署**
   ```
   ./deploy/production.sh --version vX.Y.Z
   ```

5. **生产验证** (15min)
   - [ ] Smoke test 通过
   - [ ] 监控指标正常
   - [ ] 错误率 < 0.1%
   - [ ] 响应时间无明显上升

6. **部署完成**
   - [ ] 更新 `projects/{{PROJECT}}/status.md`
   - [ ] 通知干系人 (Slack/邮件)
   - [ ] 记录部署日志

### 紧急修复部署 (随时)

1. 创建 hotfix 分支
2. CI 快速验证 (lint + 核心测试)
3. 跳过 Staging → 直接部署 Production
4. 部署后 30min 密集监控
5. 补充完整测试 + 修复

---

## 回滚方案

### 触发条件
- 错误率 > 1% 持续5分钟
- P0 功能不可用
- 数据不一致告警
- CTO 手动触发

### 回滚步骤
```
./deploy/rollback.sh --to vX.Y.Z
```

### 回滚验证
- [ ] 错误率恢复正常
- [ ] 功能恢复验证
- [ ] 数据一致性检查
